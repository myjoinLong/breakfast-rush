# 早高峰早餐摊

手机竖屏 H5 早餐摊经营游戏。清晨备好鲜肉蒸包、鸡蛋煎饼和现磨豆浆，给街坊带位、上餐、收桌，忙完一班再看账单。推进街区后可以处理外带、雇人排班、装扮摊位，参加全城早餐节。

## 本地运行

项目使用原生 HTML、CSS 和 JavaScript，无需安装前端依赖。可以直接打开 `index.html`，也可以从项目根目录启动本地服务：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)。首次进入时选一个存档位，从梧桐巷口开始。桌面浏览器可在设备模拟模式使用竖屏触摸。

普通浏览器支持完整的本地经营流程。本城榜使用本地模拟对手。激励广告和全国玩家榜需要在已开通相应能力的 TapTap 容器内运行。游戏存档保存在当前浏览器或容器中。
