# 玩法与结构

## 从开摊到换街区

1. 选存档，在梧桐巷口跟随点炉和接待教学。开摊前可按客流预估调整备货与定价。
2. 把街边排队的客人拖到空桌，也可先选客人再点桌位。一到四位坐一张桌，五到八位需要两张相邻空桌。
3. 餐点做完后点桌上餐。顾客结账离开后点桌收拾。到地铁广场后，外带客人可使用打包台接单与交付。
4. 收摊后核对销售、采购、人工和损耗。攒下资金添设备、雇搭档和升级摊位，再按生涯目标推进街区。

闲时可翻熟客手账和纪念册、换桌椅或挂灯。小雨、晴天和多云会改变街景，天气还会影响进货建议与来客。营业时可自行选择激励视频，让临时搭档帮忙带位、上餐、收桌及办理外带。

## 源码入口

| 文件 | 维护内容 |
| --- | --- |
| `index.html` | 页面入口、样式与脚本加载顺序 |
| `game.js` | 存档、营业状态、订单与食材、日结、事件和按钮分发 |
| `street.js`、`street.css` | 街景、天气、桌位和人物图层、触控拖放 |
| `operations.js`、`management.css` | 备货、员工、设备、装扮及经营选项 |
| `career.js`、`journal.css` | 街区进度、手账及页面呈现 |
| `rankings.js`、`taptap-ranks.js` | 本城模拟对手、全国榜及 TapTap 排行榜桥接 |
| `audio.js`、`assets/audio/` | 场景 BGM、环境音、事件音效、角色短语 |
| `taptap-ads.js` | TapTap 激励广告加载、播放和完成回调 |
| `mobile.css`、`breakfast-art.css`、`market.css`、`style.css` | 手机布局、图像呈现及通用样式 |

## 发包前复测

- 用手机竖屏跑通选档、首班教学、拖客、上餐、收桌、结算和继续下一天，刷新后检查当前存档。
- 在地铁广场验证两桌拼桌、外带和库存不足的反馈。切换天气与画面选项，检查营业区层级、顶部避让和底部导航。
- 在 TapTap 自测包分别走完激励视频、提前退出与广告不可用。完整播放后检查到账与重复回调处理。
- 在 TapTap 验证全国榜授权、记录满七个营业日后的成绩上传、自己的名次和加载失败后的重试。

涉及 TapTap SDK 的流程需要用目标自测包在客户端核对。
